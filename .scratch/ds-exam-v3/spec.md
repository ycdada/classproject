# 数据结构智能出卷系统功能规格

## 目标与使用者

系统面向数据结构课程教师，覆盖课程材料整理、知识点维护、题库管理、范围确认、组卷审核和试卷导出。当前版本提供教师端，不包含学生答题端。

## 核心业务流程

```text
上传课程材料 → 查看解析内容 → 提取并维护知识树
       ↓
维护题库 → 填写出卷需求 → 提出并确认考查范围
       ↓
按确认范围组卷 → 审核题目草稿 → 编辑试卷 → 导出
```

组卷需求包含标题、教学进度、考试范围、重点说明、关联材料、总分、时长、题型分布和难度分布。系统先提出可编辑的考查范围；确认后才能提交组卷。

## 功能范围

### 课程材料与知识树

- 支持上传课程材料并查看材料列表、详情和解析文本。
- 支持从材料提取章、节、知识点层级的知识树。
- 知识节点可记录定义、关键词、教学重点和解题步骤。
- 教师可查看、编辑知识节点，并维护节点层级。

### 题库

- 支持题目新增、编辑、删除、分页、条件筛选和关键词检索。
- 题目记录题型、难度、章节、知识点、题干、选项、答案、解析和来源。
- 支持以 JSON 或 XLSX 文件批量导入题目。
- 支持向量索引和语义检索。

### 考查范围与组卷

- 系统依据出卷需求和课程知识树提出考查范围。
- 教师可编辑范围节点、调整纳入状态并确认范围。
- 组卷接口要求提供已确认的范围。
- 试卷从题库中选择题目；数量不足时生成待审核的题目草稿，不将草稿直接加入题库或试卷。
- 组卷结果保存试卷及其题目关联，并返回缺题草稿信息。

### 草稿审核与试卷

- 教师可查看待处理草稿、编辑草稿、接受或拒绝草稿。
- 接受的草稿创建为题库题目并建立向量索引。
- 支持查看、列表和删除试卷，以及调整试卷题目、分值与顺序。
- 支持导出 DOCX、PDF、TXT 试卷及答题卡。

### 教学助手

- 提供对话入口，支持搜题、知识问答和组卷相关操作。
- 组卷操作遵循考查范围确认及题目草稿审核流程。

## 页面

前端包含首页、材料列表、材料详情、知识树、题库、组卷向导、试卷列表、试卷预览和题目草稿页面。

## 后端模块

- `routers/`：材料、知识、题目、范围、试卷、草稿和对话 API。
- `services/`：材料解析、知识提取、题目维护、范围构建、组卷装配、草稿审核、检索和导出。
- `models/` 与 `schemas/`：SQLite 实体及接口数据结构。
- `agent_v2/`：基于 LangGraph 的教学助手流程。

## 技术与数据

- 前端：React、TypeScript、Vite、Ant Design、React Router、Zustand。
- 后端：Python、FastAPI、SQLAlchemy 异步数据库访问。
- 结构化数据：SQLite；语义向量：ChromaDB。
- 大模型调用：DeepSeek 兼容接口；文本向量由本地中文 embedding 模型生成。
- 本地数据目录：`backend/data/`、`backend/uploads/` 和 `backend/checkpoints.db`。

## 验证方式

- 后端：在 `backend/` 执行 `.venv\Scripts\python.exe -m pytest -v`。
- 前端：在 `frontend/` 执行 `npm run build`。
- 手工走查：材料上传与知识树维护、题库操作、范围确认后组卷、草稿处理、试卷编辑和导出。

## 当前不包含

- 学生账号、在线作答、自动阅卷和成绩管理。
- 多租户及复杂角色权限。
- 教师未审核草稿直接进入题库或试卷的流程。
