# 数据结构智能出卷系统周中检查材料

## 一、技术路线

### 前端技术

- React 18、TypeScript、Vite、Ant Design、React Router、Zustand。

### 后端技术

- Python 3.11、FastAPI、SQLAlchemy、SQLite、LangGraph。

### 智能能力

- 使用大模型接口支持知识问答、语义搜题和组卷辅助。
- 使用本地中文向量模型和 ChromaDB 支持课程资料与题目检索。
- 组卷前先确认考查范围，题目不足时生成待审核草稿。

## 二、系统架构

```text
┌──────────────────────────────────────────┐
│              React 教师端                  │
│ 材料 │ 知识树 │ 题库 │ 组卷 │ 草稿 │ 试卷 │
└──────────────────┬───────────────────────┘
                   │ HTTP / JSON / SSE
┌──────────────────▼───────────────────────┐
│              FastAPI 服务层                │
│ materials │ knowledge │ questions │ exams │
│ scopes │ drafts │ chat                   │
└───────────┬──────────────┬───────────────┘
            │              │
┌───────────▼──────┐ ┌─────▼────────────────┐
│ SQLite / SQLAlchemy│ │ 业务服务与智能流程    │
│ 材料、知识、题目、 │ │ 解析、提取、检索、     │
│ 试卷、草稿等数据   │ │ 范围、组卷、导出       │
└───────────────────┘ └─────┬────────────────┘
                              │
                    ┌─────────▼─────────┐
                    │ ChromaDB / 大模型 │
                    │ 向量检索与智能辅助 │
                    └───────────────────┘
```

系统采用前后端分离结构。前端负责教师端页面和交互，后端负责接口、数据保存和业务流程，SQLite 保存结构化数据，ChromaDB 保存向量检索数据，大模型接口提供智能问答和组卷辅助。

## 三、功能设计

### 1. 材料管理与知识树

- 上传和查看数据结构课程讲义、课件等材料。
- 解析材料文本，提取章、节和知识点。
- 查看、编辑和维护知识树节点。

### 2. 题库管理

- 新增、编辑、删除和检索题目。
- 按题型、难度、章节和关键词筛选题目。
- 支持 JSON 或 XLSX 批量导入题目。

### 3. 智能组卷

- 填写考试范围、题型、难度、总分和考试时长。
- 根据课程知识树提出考查范围。
- 教师调整并确认范围后，再进行组卷。
- 题库题目不足时生成待审核题目草稿。

### 4. 草稿审核与试卷处理

- 查看、编辑、接受或拒绝题目草稿。
- 接受的草稿进入题库。
- 预览试卷，调整题目顺序和分值。
- 导出 DOCX、PDF、TXT 试卷及答题卡。

### 5. 教学助手

- 支持课程知识问答。
- 支持按知识点和关键词搜题。
- 支持辅助填写组卷需求和处理组卷流程。

## 六、系统演示

演示时按以下顺序操作：

1. 启动后端和前端服务，打开教师端首页。
2. 进入“材料”页面，查看或上传数据结构课程资料。
3. 打开材料详情，查看解析文本。
4. 进入“知识树”，提取并查看课程知识点。
5. 进入“题库”，查看题目或批量导入示例题目。
6. 进入“组卷”，填写考试范围、题型、难度、总分和时长。
7. 调整并确认系统提出的考查范围。
8. 提交组卷，查看试卷和题目草稿。
9. 在“草稿”页面审核题目。
10. 在“试卷”页面预览、调整并导出试卷。

建议准备以下演示材料：课程 PDF 或 PPT、示例题库、已配置的演示数据、关键页面截图和备用录屏。

## 八、问题和难点

1. 大模型功能需要配置 API 密钥，未配置时智能问答和智能组卷无法完整运行。
2. 课程资料格式较多，材料解析效果需要针对 PDF 和 PPT 分别验证。
3. 题目质量需要教师审核，智能生成内容不能直接作为最终题目使用。
4. 向量模型首次运行需要下载模型，可能受到网络和本机环境影响。
5. DOCX、PDF 和答题卡导出需要在不同电脑环境中检查排版效果。
6. 最终提交前需要确认演示数据库、课程资料和配置文件的完整性。
